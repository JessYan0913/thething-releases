# TheThing Releases

TheThing 桌面版安装包（DMG）官方发布仓库。

> 本仓库仅存放编译产物（安装包），**不包含源代码**。源码仓库保持私有。

## 最新版本

- [TheThing v0.12.0](https://github.com/JessYan0913/thething-releases/releases/tag/v0.12.0)

## 文件说明

| 文件 | 适用 |
|------|------|
| `The.Thing-<version>-arm64.dmg` | Apple Silicon（M1/M2/M3/M4） |
| `The.Thing-<version>.dmg` | Intel Mac |

> 未签名构建：首次打开需在「系统设置 → 隐私与安全性 → 仍要打开」，或右键 → 打开。
